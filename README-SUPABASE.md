# ตั้งค่า Supabase (ฐานข้อมูล + ระบบล็อกอิน)

ทำครั้งเดียว ใช้เวลาประมาณ 15 นาที · ทุกขั้นตอนใช้แผนฟรี

---

## 1. สร้างโปรเจกต์

1. เข้า <https://supabase.com> → **Start your project** → สมัคร/เข้าสู่ระบบด้วย GitHub หรืออีเมล
2. กด **New project**
   - **Name**: `sapara-council`
   - **Database Password**: ตั้งรหัสที่จำได้ (เก็บไว้ให้ดี ใช้ตอนกู้ข้อมูล)
   - **Region**: เลือก **Southeast Asia (Singapore)** — ใกล้ไทยที่สุด เว็บจะเร็ว
3. รอสร้างเสร็จประมาณ 2 นาที

---

## 2. สร้างตารางและกฎความปลอดภัย

1. เมนูซ้าย → **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ → คัดลอกทั้งหมด → วางในช่อง
3. กด **Run** (มุมขวาล่าง)
4. ควรขึ้น `Success. No rows returned`

ไฟล์นี้จะสร้างให้ทั้งหมด: ตาราง 10 ตาราง · ฟังก์ชันตรวจสิทธิ์ · กฎ Row Level Security ·
เปิด Realtime · และที่เก็บรูปภาพ (bucket ชื่อ `photos`)

> รันซ้ำได้ ไม่ทำให้ข้อมูลเดิมหาย

---

## 3. เปิดระบบล็อกอินด้วยอีเมล

1. เมนูซ้าย → **Authentication** → **Sign In / Providers**
2. เปิด **Email** ให้เป็น Enabled
3. **สำคัญ** — เลื่อนหา **Confirm email** แล้ว **ปิด** ไว้ก่อน

### ทำไมต้องปิด Confirm email

ระบบส่งอีเมลในตัวของ Supabase แผนฟรีส่งได้แค่ **2 ฉบับต่อชั่วโมง**
และ**ส่งได้เฉพาะอีเมลของคนในทีมโปรเจกต์เท่านั้น** ใช้กับทั้งโรงเรียนไม่ได้

เมื่อปิดไว้ นักเรียนสมัครแล้วเข้าใช้งานได้ทันที
ส่วนการยืนยันตัวตนจริง ๆ มาจาก **คลังรายชื่อนักเรียน** ซึ่งเข้มกว่า —
สมัครได้เฉพาะคนที่มีชื่อ ชั้น เลขที่ และรหัสนักเรียนตรงกับที่โรงเรียนบันทึกไว้

### ถ้าอยากได้อีเมลยืนยันจริง (ทำทีหลังได้)

1. สมัคร <https://resend.com> (ฟรี 3,000 ฉบับ/เดือน · 100 ฉบับ/วัน)
2. Supabase → **Project Settings** → **Authentication** → **SMTP Settings**
   → เปิด **Enable Custom SMTP** แล้วกรอกค่าจาก Resend
3. กลับไปเปิด **Confirm email**
4. แก้ `public/js/config.js` เป็น `window.REQUIRE_EMAIL_CONFIRM = true;`

---

## 4. เอาค่ามาใส่ในเว็บ

1. เมนูซ้าย → **Project Settings** (รูปเฟือง) → **API**
2. คัดลอก 2 ค่านี้
   - **Project URL**
   - **anon public** key
3. เปิดไฟล์ `public/js/config.js` แล้วกรอก

```js
window.SUPABASE_CONFIG = {
  url: 'https://xxxxxxxxxxxx.supabase.co',
  anonKey: 'eyJhbGciOi...'
};
```

> คีย์ `anon` **เปิดเผยได้ ไม่ใช่ความลับ** — ความปลอดภัยมาจากกฎ Row Level Security
> **ห้าม**เอา `service_role` key มาใส่เด็ดขาด เพราะคีย์นั้นข้ามกฎทั้งหมดได้

---

## 5. สร้างบัญชีแอดมิน

1. **Authentication** → **Users** → **Add user** → **Create new user**
   - Email: อีเมลของครูที่ปรึกษาหรือประธานสภานักเรียน
   - Password: ตั้งรหัสผ่าน
   - ติ๊ก **Auto Confirm User**
2. สร้างเสร็จแล้ว **คัดลอก User UID** (ข้อความยาว ๆ ในคอลัมน์ UID)
3. **SQL Editor** → New query → รันคำสั่งนี้ (แทน UID ด้วยของจริง)

```sql
insert into public.admins (id, name)
values ('วาง-UID-ที่คัดลอกมา-ตรงนี้', 'ครูที่ปรึกษาสภานักเรียน');
```

จากนี้เข้า `intex5.html` ด้วยอีเมลและรหัสผ่านนั้นได้เลย

> อยากมีแอดมินหลายคน ก็สร้าง user เพิ่มแล้ว insert เพิ่มอีกแถว

---

## 6. นำเข้าคลังรายชื่อนักเรียน

**วิธีที่ 1 — ผ่านหน้าเว็บ (แนะนำ)**
เข้าโหมดแอดมิน → **รายชื่อนักเรียน** (`intex6.6.html`) → **นำเข้าจากไฟล์ CSV**
ไฟล์ต้องมี 4 คอลัมน์ตามลำดับ: รหัสนักเรียน, ชื่อ-นามสกุล, ชั้น, เลขที่ (บันทึกเป็น UTF-8)
กดปุ่ม “ดาวน์โหลดไฟล์ตัวอย่าง” เพื่อดูรูปแบบ

**วิธีที่ 2 — ผ่าน SQL**

```sql
insert into public.roster (sid, name, room, number) values
  ('20001', 'เด็กหญิงกวางน้อย ใจดี', 'ม.4/2', '12'),
  ('20002', 'เด็กชายภูผา รักเรียน',  'ม.4/2', '13');
```

## กฎความปลอดภัยที่ตั้งไว้ให้

| ข้อมูล | นักเรียนทั่วไป | แอดมิน |
|---|---|---|
| คลังรายชื่อ | อ่านได้ | อ่าน/แก้ได้ |
| บัญชีนักเรียน | เห็นเฉพาะของตัวเอง | เห็นทั้งหมด |
| ผลโหวต | อ่านได้ทั้งหมด (เป็นข้อมูลส่วนรวม) | อ่าน/แก้ได้ |
| **ผลประเมินสภาพจิตใจ** | **เห็นเฉพาะของตัวเอง** | เห็นทั้งหมด |
| ปัญหาที่แจ้ง | เห็นเฉพาะที่ตัวเองแจ้ง · แก้สถานะไม่ได้ | เห็นทั้งหมด · เปลี่ยนสถานะได้ |
| งบประมาณ | อ่านได้ | อ่าน/แก้ได้ |
| คะแนนเว็บไซต์ | อ่านได้ · แก้เฉพาะของตัวเอง | อ่าน/แก้ได้ |

กฎเหล่านี้บังคับที่**ฝั่งฐานข้อมูล** ไม่ใช่ที่หน้าเว็บ — ต่อให้มีคนแก้ JavaScript ในเบราว์เซอร์
ก็ยังอ่านข้อมูลของคนอื่นไม่ได้

การตรวจกับคลังรายชื่อตอนสมัครก็บังคับที่ฐานข้อมูลด้วย (ฟังก์ชัน `matches_roster`)

---

## โควตาแผนฟรีของ Supabase

- ฐานข้อมูล 500 MB · ที่เก็บไฟล์ 1 GB · ผู้ใช้ 50,000 คน/เดือน
- **โปรเจกต์จะถูกพักอัตโนมัติถ้าไม่มีคนใช้งานติดต่อกัน 1 สัปดาห์**
  กดปุ่ม Restore ใน Dashboard เพื่อเปิดกลับมาได้ (ข้อมูลไม่หาย)
  ถ้าใช้จริงทั้งโรงเรียนทุกวันจะไม่เจอปัญหานี้

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| หน้าเว็บขึ้น “โหมดเครื่องเดียว” ทั้งที่กรอกค่าแล้ว | ตรวจว่า `url` และ `anonKey` ใน `config.js` ไม่มีช่องว่างหรือเครื่องหมายคำพูดเกิน |
| ลงทะเบียนแล้วขึ้น “ข้อมูลไม่ตรงกับคลังรายชื่อ” | ชื่อ ชั้น เลขที่ ต้องตรงกับคลังทุกตัวอักษร (รวมเว้นวรรค) หรือปิดสวิตช์ตรวจสอบในหน้า `intex6.6.html` |
| เข้าแอดมินแล้วขึ้น “ไม่มีสิทธิ์แอดมิน” | ยังไม่ได้ `insert` UID ลงตาราง `admins` (ขั้นตอนที่ 5) |
| รูปไม่ขึ้น | ตรวจว่ารัน `schema.sql` ครบ โดยเฉพาะส่วนที่ 6 ที่สร้าง bucket `photos` |
| ข้อมูลไม่อัปเดตให้อัตโนมัติ | ตรวจว่ารันส่วนที่ 5 ของ `schema.sql` (เปิด Realtime) แล้ว |
