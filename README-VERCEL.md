# ขึ้นเว็บจริงด้วย Vercel

ฟรีสำหรับเว็บแบบนี้ · มี HTTPS ให้อัตโนมัติ · ผูกโดเมน `.ac.th` ของโรงเรียนได้

---

## วิธีที่ 1 — ผ่าน GitHub (แนะนำ เพราะแก้ไขแล้วเว็บอัปเดตเอง)

1. สร้าง repository ใหม่บน <https://github.com> (ตั้งเป็น Private ก็ได้)
2. อัปโหลดไฟล์ทั้งโฟลเดอร์นี้ขึ้นไป (ลากวางในหน้า GitHub ได้เลย)
3. เข้า <https://vercel.com> → **Sign up with GitHub**
4. **Add New** → **Project** → เลือก repository ที่เพิ่งสร้าง → **Import**
5. หน้าตั้งค่า ปล่อยค่าเริ่มต้นทั้งหมด (`vercel.json` ตั้งให้เสิร์ฟจาก `public/` แล้ว)
6. กด **Deploy** → รอประมาณ 1 นาที → ได้ลิงก์แบบ `sapara-council.vercel.app`

ต่อจากนี้ทุกครั้งที่แก้ไฟล์บน GitHub เว็บจะอัปเดตให้อัตโนมัติภายในไม่กี่วินาที

---

## วิธีที่ 2 — ลากไฟล์ขึ้นโดยตรง

1. เข้า <https://vercel.com> → สมัครและเข้าสู่ระบบ
2. **Add New** → **Project** → เลื่อนลงหา **Deploy a folder** / ลากโฟลเดอร์ทั้งอันวางในหน้าเว็บ
3. กด Deploy

*(วิธีนี้ง่ายกว่า แต่ต้องลากขึ้นใหม่ทุกครั้งที่แก้ไฟล์)*

---

## ผูกโดเมนของโรงเรียน

1. ใน Vercel → โปรเจกต์ → **Settings** → **Domains** → **Add**
2. ใส่โดเมนที่ต้องการ เช่น `sapara.rka.ac.th`
3. Vercel จะบอกค่า **CNAME** ที่ต้องไปตั้ง
4. เอาค่านั้นไปให้ผู้ดูแลโดเมนของโรงเรียนตั้งค่าใน DNS
5. รอไม่เกิน 1 ชั่วโมง จะได้ HTTPS อัตโนมัติ

---

## เช็กลิสต์ก่อน Deploy

- [ ] กรอกค่า Supabase ใน `public/js/config.js` แล้ว
- [ ] รัน `supabase/schema.sql` ใน SQL Editor แล้ว
- [ ] สร้างบัญชีแอดมินและ insert UID ลงตาราง `admins` แล้ว
- [ ] แก้เบอร์โทรและลิงก์ Facebook ใน `CONTACT` ที่ `public/js/app.js`
- [ ] เปลี่ยนรหัสผ่านแอดมินสำรอง `ADMIN_PASSWORD` ใน `public/js/app.js`

---

## หลัง Deploy แล้วต้องทำ

กลับไปที่ Supabase → **Authentication** → **URL Configuration**
ใส่ลิงก์เว็บจริงในช่อง **Site URL** เช่น `https://sapara-council.vercel.app`
เพื่อให้ลิงก์ในอีเมล (ตั้งรหัสผ่านใหม่ / ยืนยันอีเมล) พากลับมาที่เว็บถูกที่

---

## ข้อควรรู้

- ไฟล์ที่ชื่อมีจุด เช่น `intex2.1.html` ใช้งานบน Vercel ได้ปกติ
- `public/js/config.js` เป็นไฟล์สาธารณะ ใครก็เปิดดูได้ — ใส่ได้เฉพาะ `anon` key เท่านั้น
- ถ้าเปิดเว็บแล้วขึ้น 404 ให้ตรวจว่า **Root Directory** ใน Vercel ตั้งเป็นรากของ repo
  (ไม่ใช่ `public`) เพราะ `vercel.json` จัดการเรื่องนี้ให้แล้ว
